# Out-of-Band SQL Injection

## چه زمانی بررسی می‌شود؟

وقتی پاسخ صفحه کانال مناسبی برای Boolean یا Time نمی‌دهد اما دیتابیس می‌تواند درخواست شبکه بیرونی بسازد. این روش به امکانات دیتابیس، سطح دسترسی و Network Egress وابسته است.

## ملاحظات قبل از تست

- فقط از دامنه OOB خودت استفاده کن.
- مجوز آزمون تعاملات بیرونی را در Scope بررسی کن.
- هیچ داده حساس واقعی در DNS یا HTTP ارسال نکن.
- ابتدا فقط یک نشانگر تصادفی بدون داده بساز.

## ثبت نشانگر

```text
Token: rasad-<random-id>
Target parameter:
Database:
Expected channel: DNS / HTTP
Started at:
Interaction received:
Source address:
```

## sqlmap

برای استفاده از قابلیت OOB در sqlmap، تنظیمات سرویس و دامنه باید آگاهانه انجام شود. گزینه‌های مرتبط را فقط بعد از مطالعه خروجی help و تعیین دامنه شخصی به‌کار ببر:

```bash
sqlmap --help | grep -i -E 'dns|oob'
```

## چک‌لیست عیب‌یابی

- [ ] آیا Target اصلاً اجازه Egress دارد؟
- [ ] آیا DNS Resolver دامنه شخصی را Resolve می‌کند؟
- [ ] آیا تابع شبکه در دیتابیس فعال و مجاز است؟
- [ ] آیا نشانگر درخواست ثبت شده اما پاسخ برنامه تغییری نکرده؟
- [ ] آیا تعامل ثبت‌شده می‌تواند از سرویس دیگری باشد؟

## اثبات و گزارش

در گزارش فقط Token، زمان و نوع Interaction را ثبت کن. داده‌ای که ممکن است حساس باشد نباید در کانال OOB قرار بگیرد.
