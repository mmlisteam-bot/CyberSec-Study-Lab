# Stored XSS

## تفاوت اصلی

ورودی در سرور ذخیره و بعداً برای کاربر دیگر یا همان کاربر نمایش داده می‌شود. بنابراین مسیر ورودی و مسیر نمایش می‌توانند متفاوت باشند.

## گردش‌کار ایمن

1. با حساب آزمایشی داده با نشانگر بساز.
2. همه صفحات نمایش آن داده را بررسی کن.
3. Context هر محل نمایش را جدا ثبت کن.
4. اثبات را فقط در حساب و داده آزمایشی انجام بده.
5. داده آزمایشی را بعد از تست پاک کن.
