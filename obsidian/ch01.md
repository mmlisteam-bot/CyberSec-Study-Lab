# فصل ۰۱ — مبانی JavaScript Security

## DOM
DOM مخفف Document Object Model است و ساختار شیءگرای سند HTML را در اختیار JavaScript قرار می‌دهد.

## Critical Rendering Path
HTML → Parsing → DOM → CSS/CSSOM → Rendering → Display

## Source
Source نقطه‌ای است که داده وارد برنامه یا جریان داده می‌شود.

نمونه:
```javascript
const data = location.hash;
```

در این مثال `location.hash` یک Source است.

## Sink
Sink نقطه‌ای است که داده مصرف، تفسیر یا وارد یک عملیات حساس می‌شود.

```javascript
document.body.innerHTML = data;
```

در این مثال `innerHTML` یک Sink است.

## Data Flow
```text
SOURCE → DATA FLOW → SINK
```

وجود Source و Sink به‌تنهایی به معنی XSS نیست؛ باید داده قابل‌کنترل توسط مهاجم و جریان خطرناک به Sink نیز وجود داشته باشد.

## نکات API
- `document.URL` معتبر است؛ `document.url` استاندارد نیست.
- `location.search` معتبر است؛ `document.search` استاندارد نیست.
- `document.cookie` کوکی‌های HttpOnly را نمی‌خواند.
- `postMessage` ذاتاً Sink نیست؛ اعتبارسنجی origin/message و استفاده بعدی از داده مهم است.
