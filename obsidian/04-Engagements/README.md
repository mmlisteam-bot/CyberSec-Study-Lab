# پروژه‌های آزمون

برای هر پروژه یک پوشه جدا بساز و یادداشت‌های اجرایی را اینجا قرار بده. تکنیک‌ها و دستورهای عمومی نباید کپی شوند؛ به یادداشت اصلی در `01-Web` لینک بده.

```text
04-Engagements/
└── <project-name>/
    ├── Scope.md
    ├── Requests.md
    ├── Findings.md
    └── Evidence.md
```

از [[Finding Template]] برای یافته‌ها استفاده کن.

> این ریپو Public است. اطلاعات واقعی پروژه و مشتری را در این پوشه قرار نده.
