# CyberSec Study Lab v3

نسخه ۳ با رابط CyberSec و مسیر کامل مطالعه:

جزوه → فلش‌کارت → آزمون → Code Challenge → مرور

## تغییرات این نسخه
- منوی «جزوه» فعال و متصل به محتوای فصل است.
- منوی «آزمون» فعال است و سوال‌ها واقعاً نمایش داده می‌شوند.
- پاسخ اشتباه: پاسخ صحیح + توضیح کامل همان لحظه نمایش داده می‌شود.
- برای رفتن به سوال بعدی باید دکمه «فهمیدم، سؤال بعدی» را بزنید؛ پاسخ اشتباه فرصت حفظ کردن نکته را می‌دهد.
- پاسخ صحیح نیز توضیح آموزشی دارد.
- دکمه «از اول آزمون» اضافه شده است.
- فصل‌ها از فایل‌های data/chapters تغذیه می‌شوند.
- پیشرفت و XP در localStorage ذخیره می‌شود.

## اجرا
